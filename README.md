# soles_first — 무료 오픈소스 모션 스튜디오

원문(“애프터 이펙트에 새로운 적이 등장했습니다”)에 나온 **무료 GitHub 저장소 14개**를 저장하고,
그중 **브라우저에서 바로 돌아가는 6개**로 78초짜리 오디오비주얼 단편 **NIGHT SHIFT**를 만들었습니다.

## 오늘 밤 볼 것

```
studio/index.html   ← 더블클릭하면 열립니다(서버·설치·빌드 불필요). 소리가 나옵니다.
```

또는 로컬 서버로 열기:

```bash
cd studio && python3 -m http.server 8765    # → http://localhost:8765
```

| 단축키 | 동작 |
|---|---|
| `1`–`5` | 장면 이동 (오버추어 / 흐름 / 중력 / 데이터 / 엔딩) |
| `R` | 처음부터 |
| `M` | 소리 켜기/끄기 |
| 진행바 클릭 | 해당 장면으로 이동 |

### 장면 구성 (총 78초)

| 시간 | 장면 | 쓰인 도구 | 내용 |
|---|---|---|---|
| 0–9초 | 오버추어 | anime.js · PixiJS · Tone.js | 글자별 스태거 타이틀, 별밭과 불씨 |
| 9–29초 | 흐름 | p5.js · Tone.js | 노이즈 플로우 필드 위 1,500개 점. 킥 드럼 박자에 선 굵기·밝기가 반응 |
| 29–53초 | 중력 | matter-js · PixiJS · Tone.js | 플링코 물리. 공이 못에 부딪힐 때마다 음이 울리고 파티클이 터짐 |
| 53–69초 | 데이터 | D3 · anime.js | **앞 장면에서 실제 측정한 음별 충돌 횟수**를 방사형 막대로 그림 |
| 69–78초 | 엔딩 | 전부 | 크레딧, 다시 보기 |

연결 고리: 물리 장면의 충돌 한 번이 ① 음 재생 ② 파티클 ③ 집계(`Studio.counts`)를 동시에 만들고,
그 집계가 다음 장면 D3 차트의 입력이 됩니다. 재생할 때마다 차트가 달라집니다.
물리 장면을 건너뛰고 데이터 장면으로 바로 가면 실측값이 없어 **“시뮬레이션 값”이라고 화면에 표시**한 대체 데이터를 씁니다.

### 사용 전 확인할 점

- **“$0”는 구독료 기준입니다.** 02·07~13번은 설치·GPU·모델 가중치 내려받기가 필요하고, AI 모델은 코드와 가중치의 라이선스가 따로인 경우가 많습니다. 상업적·공공 이용 전에는 저장소별 라이선스를 직접 확인하세요. **[확인요망]**
- p5.js는 LGPL-2.1입니다. `studio/vendor/p5.min.js`는 수정하지 않은 별도 파일로 로드하므로 교체할 수 있습니다.
- “Fable 5.2 + 14개 = 완전한 모션 스튜디오”는 원문의 홍보 문구입니다. 이 저장소가 실제로 검증한 범위는 아래와 같습니다.

## 검증 내역

헤드리스 Chromium(Playwright, 소프트웨어 렌더링)에서 확인한 것:

- 처음부터 끝까지 재생, 콘솔에 스크립트 오류 없음
- `file://` 더블클릭 경로에서 클릭 시작 → 오디오 컨텍스트 `running` 확인
- 데스크톱(1280×720)·모바일(390×844) 레이아웃 스크린샷 확인
- 장면 건너뛰기 경합(타이틀 등장 중 이동) 버그 재현 후 수정 확인
- 충돌 집계 → D3 차트 실측 연결 확인 (예: 총 227회, 최다 G4 61회)

확인하지 못한 것:

- **실제 소리의 청감 품질** — 헤드리스에서는 들을 수 없어 음색·볼륨 밸런스는 사람이 들어보고 조정해야 합니다.
- **실제 GPU에서의 프레임 속도** — 테스트는 소프트웨어 렌더링이라 실시간보다 느리게 돌았습니다.
- 원문 14개 중 브라우저 외 8개의 설치·실행, 그리고 그 8개의 저장소 실존·라이선스

## 알려진 동작

- 브라우저 자동재생 정책 때문에 **재생 버튼을 눌러야** 소리가 납니다. 오디오가 4초 안에 열리지 않으면 무음으로 계속 재생합니다.
- p5.js 2.x는 로딩 시 오류 메시지 번역 파일(`en-US.json` 등)을 요청하며, 실패해도 무시됩니다(콘솔에 404/CORS 메시지가 보일 수 있음). 기능에는 영향이 없습니다.
- 개발용: `index.html?auto=1&scene=2` 로 클릭 없이 특정 장면부터 시작합니다.
