# 사실 표 (Fact card)

쓰기 전에 아래 표를 채운다. 표에 없는 사실은 본문에 쓰지 않는다.

| 항목 | 내용 | 출처(문서명·담당부서·일자) | 상태 |
|---|---|---|---|
| 구청장 직함·성명 | | | 확인/[확인요망] |
| 행사·사업명(정식 명칭) | | | |
| 일시 | | | |
| 장소 | | | |
| 대상·규모(인원) | | | |
| 예산·금액 | | | |
| 핵심 효과·수치 | | | |
| 인용 발언 | | | 확인됨/구청장 확인 대기 |
| 근거 법령·조례 | 「」 제 조 | 시행일 | 현행 확인/검증 필요(현행 미확인) |
| 문의처 | | | |

## 규칙
- 출처를 말할 수 없는 수치는 `[확인요망]`으로 둔다.
- 날짜는 연·월·일·요일을 함께 적고, 요일은 달력과 대조한다.
- 같은 사업명을 문서 내에서 다르게 쓰지 않는다.
