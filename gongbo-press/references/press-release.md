# 보도자료 구조

1. **제목(한 줄):** 핵심 메시지 + 구체적 대상. 부제는 한 줄.
2. **리드(첫 문단):** 누가, 무엇을, 언제부터, 누구에게. 육하원칙 중 핵심만.
3. **본문:** 사업 내용 → 기대 효과 → 일정·방법 순. 문단마다 사실 하나.
4. **구청장 인용:** 1건 이내. 확인된 발언이 아니면 "구청장 확인 대기"로 표시.
5. **배경·참고:** 사업 경과, 근거 법령·조례(「」 조문, 시행일).
6. **문의처:** 부서, 담당, 전화. [확인요망]이면 비워 두고 표시.

## 점검
- 제목과 리드만 읽어도 기사가 되는가.
- 숫자마다 단위·기준일이 있는가.
- 형용사("획기적", "역대 최대")는 근거가 있을 때만 쓴다.
