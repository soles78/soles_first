# 구청장 문체 카드 (빈 양식)

이 파일은 실제 연설문·보도자료 샘플 3편 이상으로 채운다. 채우기 전에는 문체를 추측하지 않는다.

| 항목 | 기록할 내용 |
|---|---|
| 자기 지칭 | (예: "저는", "구청장으로서") — 샘플에서 확인 |
| 주민 호칭 | |
| 문장 길이 | 평균 글자 수 |
| 자주 쓰는 어미 | |
| 피하는 표현 | |
| 인사·맺음 관용구 | |
| 비유·인용 습관 | |
| 숫자 표기 | 한글/아라비아, 단위 |

## 채우는 방법
1. 샘플에서 반복되는 표현을 표시한다.
2. 샘플에 없는 표현은 카드에 넣지 않는다.
3. 구청장이 고친 부분은 고친 내용을 카드에 반영한다.
