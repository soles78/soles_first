# 공보 산출물 작성 (gongbo-press)

구청장 명의의 글은 **한 문장도 사실과 어긋나면 안 되고, 구청장의 목소리로 읽혀야 한다.**
이 스킬은 쓰기 전에 사실을 고정하고, 쓴 뒤에 검증 게이트를 통과시키는 순서를 따른다.

## 핵심 원칙

**확인된 사실만 쓰고, 모르는 것은 `[확인요망]`으로 남기며, 한 건에 메시지는 하나만 둔다.**

실패하는 다섯 가지 유형:

- **지어낸 수치.** 출처 없는 예산·인원·% 는 쓰지 않는다. 없으면 `[확인요망]`.
- **직함·명칭 오류.** 직함, 기관명, 사업명, 시설명은 입력 자료와 글자 그대로 대조한다.
- **나열형.** 사업을 모두 담으려다 메시지가 사라진 글. 핵심 한 줄이 먼저다.
- **관청체.** "~하고자 합니다"가 반복되고 주어가 없는 글. 주체와 행동을 분명히 쓴다.
- **다른 사람 목소리.** 구청장 명의 글에 담당자 시각이 섞인 경우. 스타일 카드로 맞춘다.

## 워크플로

1. **접수.** 산출물 종류(보도/연설/기고/인터뷰/카드뉴스), 배포일·행사일, 매체·청중, 분량을 확인한다. 빠진 항목은 묻거나 `[확인요망]`으로 둔다.
2. **사실 고정.** 입력 자료에서 사실 표(직함, 일시, 장소, 수치, 인용, 근거)를 먼저 만든다. 표에 없는 사실은 본문에 쓰지 않는다. (`references/fact-card.md`)
3. **스타일 카드 적용.** 구청장 명의 산출물은 스타일 카드가 있으면 그것을 우선한다. 없으면 임의로 만들지 않고 기존 연설문·보도자료 샘플을 요청한다. (`references/style-card.md`)
4. **초안.** 종류별 형식을 따른다. (`references/press-release.md`, `references/speech.md`, `references/cardnews.md`)
5. **검증 게이트.** 아래 체크를 통과해야 넘긴다.
6. **인계.** 초안과 함께 `[확인요망]` 목록, 사용한 근거, 확인하지 못한 항목을 한 곳에 정리한다.

## 검증 게이트

- [ ] 본문의 모든 수치·날짜·직함·인용이 사실 표에 있다.
- [ ] 사실 표에 없는 내용은 `[확인요망]` 표시가 되어 있다.
- [ ] 법령을 인용했다면 「법령명」 조문과 시행일을 적었고, 현행 확인이 안 된 것은 "검증 필요(현행 미확인)"로 표시했다.
- [ ] 핵심 메시지가 제목과 첫 문단에 있다.
- [ ] 구청장 인용문은 확인된 발언이거나 구청장 확인 대기 상태로 표시했다.
- [ ] 정중체로 통일했고, 같은 어미가 세 번 연속되지 않는다.
- [ ] 공문서 파일이 필요하면 HWPX/DOCX 검증 파이프라인을 따른다.

## 하지 않는 것

- 구청장 발언을 지어내지 않는다. 인용문 초안은 "구청장 확인 필요"를 붙인 제안으로만 쓴다.
- 출처 없는 통계, 타 지자체 비교 수치, 순위를 쓰지 않는다.
- 선거·정당·특정인 비방으로 읽힐 표현을 쓰지 않는다.
